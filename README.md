# 📰 News App (Flutter)

A modern Flutter News App that fetches real-time news using API integration. This app allows users to browse the latest headlines, explore different categories, and read detailed news articles with a clean and user-friendly interface.

---

## 🚀 Features

- 📡 Fetch real-time news from API  
- 🗂️ Category-based news (General, Sports, Health, etc.)  
- 📰 Latest headlines display  
- 🔍 Detailed news view screen  
- ⚡ Fast and responsive UI  
- 🔄 Pull-to-refresh functionality  

---

## 🛠️ Technologies Used

- Flutter (Dart)  
- REST API integration  
- HTTP package  
- JSON parsing & model mapping  

---

## 📦 API Used

- https://newsapi.org/

## ⚙️ Installation

1. Clone the repository  
git clone https://github.com/gillzaib021-code/News_App.git  

2. Navigate to project folder  
cd News_App  

3. Get dependencies  
flutter pub get  

4. Run the app  
flutter run
